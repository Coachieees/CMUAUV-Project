ตอนนี้ผมได้ติดตั้ง Underwater Ultrasonic Sensor (UART Control) จำนวน 2 ตัว (สำหรับวัดตำแหน่ง x และ y axis) เข้าไปกับ Raspberry Pi 5 โดยผ่าน TXS0108E Logic level Converter โดยมีรายละเอียดการเชื่อมต่อดังนี้
- การเชื่อมต่อของเซนเซอร์ตัวที่ 1 (x)
Raspberry Pi5		TXS0108E	สายฝั่งเซนเซอร์
Pin 7 (GPIO4 / TXD3) 	➡ A1 ⇔ B1 ➡ 	สายสีเหลือง (RX)
Pin 29 (GPIO5 / RXD3) 	⬅ A2 ⇔ B2 ⬅ 	สายสีขาว (TX)

- การเชื่อมต่อของเซนเซอร์ตัวที่ 2 (y)
Raspberry Pi5		TXS0108E	สายฝั่งเซนเซอร์
Pin 32 (GPIO12 / TXD5) 	➡ A3 ⇔ B3 ➡ 	สายสีเหลือง (RX)
Pin 33 (GPIO13 / RXD5) 	⬅ A4 ⇔ B4 ⬅ 	สายสีขาว (TX)

ผมได้แนบไฟล์โค้ดให้ดังนี้
- auv_bridge.py ซึ่งเป็น ROS Node ที่รันบน Raspberry Pi เพื่ออ่านค่าจากเซนเซอร์ต่าง ๆ แล้วส่งค่าไปแสดงผลยัง Ubuntu PC
- dashboard.py ซึ่งเป็นโค้ดที่รันบน Ubuntu PC เพื่อรับค่าจาก AUV มาแสดงผลและป้อน Input เพื่อควบคุม AUV
- GL081MT.py ซึ่งเป็นโค้ดที่ผมเคยใช้รันเพื่อทดสอบการอ่านค่าจาก Underwater Ultrasonic Sensor ทั้งสองตัวนี้
ผมต้องการคำแนะนำจากคุณว่าระหว่าง
1. นำโค้ด GL081MT.py ไปรวมเข้าใน auv_bridge.py เพื่ออ่านค่าเซนเซอร์ แล้ว pack ข้อมูลรวมกันกับค่าจากเซนเซอร์อื่นๆ แล้วส่งไปยังแสดงผลบน dashboard.py
2. เขียนไฟล์แยกเป็น Node ใหม่ไปเลย
คุณจะแนะนำแบบไหนดี ให้ตอบผมแค่ว่าแบบไหนดีกว่าแต่ยังไม่ต้องแก้โค้ดมานะครับ และผมขอวิธีการตั้งค่่า Config File ใน Raspberry Pi5 (Ubuntu server OS) ด้วยว่าต้องเปิดพอร์ท UART3 กับ UART5 อย่างไร
